Adding a new renderer

  1. Write a pure render_x(data, title="") -> str in visuals.py.
  2. Register it in the RENDERERS dict.
  3. Add an entry to EXAMPLES — that is what this page renders.
  4. Add a test in tests/test_visuals.py.

Specs are rendered once when content loads, so a malformed diagram fails the build instead of showing up as a blank panel.
